# ULM-4B v1.0 사투리 강도 실모델 테스트

2026-09-29, frozen Arm B를 실제 GPU 환경에서 동일 조건으로 비교했습니다. 이번 3개 프롬프트에서는 기대한 `1 < 2 < 3` 경향을 확인하지 못했습니다. 이 결과는 제한된 greedy 샘플이며 native-speaker human evaluation이 아닙니다.

## 조건

- Model: ULM-4B v1.0, frozen Arm B
- Hardware: AWS EC2 g6e.xlarge, NVIDIA L40S
- Endpoint: `/v1/chat/completions`
- 3 prompts × strength 1/2/3 = 9 outputs
- strength 0 sanity = 3 outputs
- `temperature=0`, `stream=false`, `repetition_penalty=1.1`, `no_repeat_ngram_size=3`, thinking disabled
- 모델 다운로드·추가 학습·weight merge 없음
- 테스트 종료 후 서버와 GPU process를 종료하고 EC2 stopped 상태를 확인
- frozen base/adapter digest는 v1.0 release contract와 동일

## 출력

### Prompt A

친구가 약속 시간보다 40분이나 늦게 왔다. 화가 나긴 했는데 진짜 싸울 정도는 아니고, 친한 친구한테 장난 섞어서 한마디 하고 싶다. 실제로 말하는 것처럼 자연스럽게 2~4문장으로 답해.

| Strength | Output |
| --- | --- |
| 1 | 너야 진짜 늦었네? 진짜 늦었다니까. 근데 너무 늦은 게 아니라서 그냥 장난치면서 뭐라고 해. |
| 2 | 너야 진짜 늦었나? 진짜 늦었다니까. 근데 너무 늦은 게 아니라면 그냥 장난치면서 뭐라고 해. |
| 3 | 너야 진짜 늦었나? 진짜 늦었다니까. 근데 너무 늦은 게 아니라면 그냥 장난치면서 뭐라고 해. |

2와 3이 동일합니다. 일부 어미 차이는 있으나 강도 증가를 입증하기 어렵고, 40분 정보와 직접적인 장난스러운 한마디도 충분히 보존되지 않았습니다.

### Prompt B

오늘 학교 끝나고 친구들이랑 울산 성남동에 놀러 가려고 하는데, 비도 좀 오는 것 같고 배도 고프다. 친구 한 명은 집에 그냥 가자고 하고 다른 한 명은 끝까지 놀자고 한다. 내가 친구한테 자연스럽게 말하듯이 뭐라고 할지 3~5문장으로 답해.

| Strength | Output |
| --- | --- |
| 1 | 친구네, 오늘 학교 끝나면 우리 둘이서 성남동으로 놀러 갈까? 비가 오는데 배도 너무 고포니까. |
| 2 | 친구네, 오늘 학교 끝나면 우리 둘이서 성남동으로 놀러 갈까? |
| 3 | 친구네, 오늘 학교 끝나면 우리 둘이서 성남동으로 놀러 갈까? 비가 오는데 배도 너무 고포니까. |

1과 3이 동일하고 2는 더 짧습니다. 세 출력 모두 요청한 3~5문장을 충족하지 못했고 친구들 사이의 의견 충돌도 충분히 반영하지 못했습니다.

### Prompt C

내일 아침 일찍 일어나야 하는데 친구가 밤늦게까지 게임하자고 한다. 친한 친구한테 자연스럽게 거절하면서 장난스럽게 말해줘. 2~4문장.

| Strength | Output |
| --- | --- |
| 1 | 야 내일 아침에 학교 가는 시간인데 너 게임하라고? 진짜 야! |
| 2 | 야 내일 아침 쫌 일찍 일어날려고 하는데 너 밤늦하게까지 게임하라고? 진짜야 나 오늘 밤 늦게까지 게임을 할 수 있나? |
| 3 | 야 내일 아침 쫌 일찍 일어날려고 하는데 너 밤늦하게까지 게임하라고? 진짜야 그거야. |

2/3에 구어·비표준 형태가 늘지만 3이 2보다 더 강한 울산 방언이라고 확인하기 어렵습니다. 명확한 거절과 자연스러움도 부족합니다.

## Strength 0 sanity

- A: `너 진짜 늦었나? 진짜 늦었다니까. 근데 너무 늦은 게 아니라서 그냥 장난치면서 뭐라고 해.`
- B: `친구네, 오늘 학교 끝나면 우리 둘이서 성남동으로 놀러 갈까?`
- C: `야 내일 아침에 학교 가는 거 알잖아? 야 오늘 밤 늦게까지 게임을 하라고? 야 내일 학교는 안 가.`

B0가 B2와 동일하고 A0에도 구어적 `늦었나?`가 남아 이 샘플에서는 0/1/2/3 분리가 안정적이지 않았습니다.

## 결론

| 항목 | 관찰 |
| --- | --- |
| 1 → 2 → 3 단조 증가 | 확인되지 않음 |
| 울산 고유 표현의 안정적 증가 | 확인되지 않음 |
| 과도한 `아이가/데이/뭐하노/퍼뜩` 반복 | 관찰되지 않음 |
| 의미 보존 | 일부 누락·추가·거절 불명확 |
| 형식 준수 | Prompt B에서 실패 |
| human evaluation | 미실시 |

따라서 현재 prompt-based dialect strength를 학습된 강도 제어처럼 표현하면 안 됩니다. 더 넓은 prompt set, sampling 조건, native-speaker 평가가 필요합니다.
