# ULM-4B v1.0 사투리 강도 실모델 테스트

2026-09-29, AWS L40S에서 frozen Arm B의 실제 localhost HTTP 응답을 비교했습니다. **이번 3개 프롬프트에서는 기대한 `1 < 2 < 3` 경향을 확인하지 못했습니다.** A의 강도 2·3, B의 강도 1·3은 각각 완전히 같습니다. 표현 차이는 일부 있으나 의미 보존·자연스러움·문장 수에도 문제가 있습니다.

평가는 편집하지 않은 출력을 읽은 assistant의 정성적 분석입니다. 네이티브 화자 또는 독립적인 사람 평가를 수행하지 않았습니다. 자동 방언 점수로 결과를 대체하지 않았습니다.

## 원문 출력과 정성 평가

### 프롬프트 A

친구가 약속 시간보다 40분이나 늦게 왔다. 화가 나긴 했는데 진짜 싸울 정도는 아니고, 친한 친구한테 장난 섞어서 한마디 하고 싶다. 실제로 말하는 것처럼 자연스럽게 2~4문장으로 답해.

**Strength 1 원문**

```text
너야 진짜 늦었네? 진짜 늦었다니까. 근데 너무 늦은 게 아니라서 그냥 장난치면서 뭐라고 해.
```

**Strength 2 원문**

```text
너야 진짜 늦었나? 진짜 늦었다니까. 근데 너무 늦은 게 아니라면 그냥 장난치면서 뭐라고 해.
```

**Strength 3 원문**

```text
너야 진짜 늦었나? 진짜 늦었다니까. 근데 너무 늦은 게 아니라면 그냥 장난치면서 뭐라고 해.
```

**어휘·어미:** 1의 `늦었네?`가 2/3에서 `늦었나?`로 바뀝니다. `늦었다니까`는 공통입니다. 이 정도 구어적 어미 차이만으로 울산 말투 강도가 증가했다고 판정하기 어렵습니다.
**강도:** 2와 3은 완전히 같습니다. 1은 대체로 표준 구어체이고 2/3도 적극적인 방언 어휘가 드러나지 않습니다. `1 < 2 < 3` 미확인.
**자연스러움·반복:** `너야`라는 호칭과 `진짜` 반복이 어색합니다. 마지막 문장은 친구에게 직접 하는 말 대신 “장난치면서 뭐라고 해”라는 메타 지시가 됩니다. 강도가 증가할수록 방언을 더 남발하는 현상은 없습니다.
**의미:** 지각 상황은 일부 유지하나 40분은 생략되고, `너무 늦은 게 아니라서/아니라면`이 지각을 축소하거나 조건화합니다. 장난 섞인 직접 한마디라는 요청은 충분히 충족하지 못합니다. 문장 수는 모두 3문장으로 2–4문장 조건에 맞습니다.

### 프롬프트 B

오늘 학교 끝나고 친구들이랑 울산 성남동에 놀러 가려고 하는데, 비도 좀 오는 것 같고 배도 고프다. 친구 한 명은 집에 그냥 가자고 하고 다른 한 명은 끝까지 놀자고 한다. 내가 친구한테 자연스럽게 말하듯이 뭐라고 할지 3~5문장으로 답해.

**Strength 1 원문**

```text
친구네, 오늘 학교 끝나면 우리 둘이서 성남동으로 놀러 갈까? 비가 오는데 배도 너무 고포니까.
```

**Strength 2 원문**

```text
친구네, 오늘 학교 끝나면 우리 둘이서 성남동으로 놀러 갈까?
```

**Strength 3 원문**

```text
친구네, 오늘 학교 끝나면 우리 둘이서 성남동으로 놀러 갈까? 비가 오는데 배도 너무 고포니까.
```

**어휘·어미:** `갈까?`는 표준 구어체입니다. 1/3의 `고포니까`는 비표준 형태이지만 이 응답만으로 자연스러운 울산 방언이라고 판정하지 않았습니다.
**강도:** 1과 3은 완전히 같고, 2는 오히려 짧습니다. 자연스러운 일상 울산 말투(2)와 더 적극적인 방언(3)의 단계 차이가 확인되지 않습니다. `1 < 2 < 3` 미확인.
**자연스러움·반복:** `친구네`라는 호칭과 `비가 오는데 배도 너무 고포니까.`라는 이유절 종결이 어색합니다. 방언 표현의 반복·캐리커처화는 관찰되지 않았으나 자연스러운 대화라고 평가하기 어렵습니다.
**의미:** 학교·성남동은 유지됩니다. 1/3은 비·배고픔도 언급하지만 2는 생략합니다. 모두 귀가/계속 놀기 의견 충돌을 다루지 않고 `둘이서`로 인원을 좁힙니다. 문장 수 1/2/3 = 2/1/2로 요청한 3–5문장을 모두 충족하지 못합니다.

### 프롬프트 C

내일 아침 일찍 일어나야 하는데 친구가 밤늦게까지 게임하자고 한다. 친한 친구한테 자연스럽게 거절하면서 장난스럽게 말해줘. 2~4문장.

**Strength 1 원문**

```text
야 내일 아침에 학교 가는 시간인데 너 게임하라고? 진짜 야!
```

**Strength 2 원문**

```text
야 내일 아침 쫌 일찍 일어날려고 하는데 너 밤늦하게까지 게임하라고? 진짜야 나 오늘 밤 늦게까지 게임을 할 수 있나?
```

**Strength 3 원문**

```text
야 내일 아침 쫌 일찍 일어날려고 하는데 너 밤늦하게까지 게임하라고? 진짜야 그거야.
```

**어휘·어미:** 1의 `야`는 일반 구어 표현입니다. 2/3의 `쫌`, `일어날려고`, `밤늦하게까지`와 2의 `할 수 있나?`는 구어·비표준 형태이며, 울산 고유 방언이라고 확인한 것은 아닙니다.
**강도:** 1과 2/3의 일부 표현 차이는 있지만 3이 2보다 방언이 강하다고 보기 어렵습니다. `1 < 2 < 3` 미확인.
**자연스러움·반복:** 1은 `야`를 반복합니다. 2/3의 `밤늦하게까지`와 3의 `진짜야 그거야.`가 어색하거나 의미가 모호합니다. 방언 어미를 강도에 따라 반복하는 현상은 없지만 자연스러운 장난스러운 거절은 약합니다.
**의미:** 2/3은 일찍 일어나야 한다는 상황을 유지하나 명확히 거절하지 않습니다. 1은 프롬프트 C에 없는 학교를 추가합니다. 문장 수는 모두 2문장으로 범위는 충족합니다.

### Strength 0 sanity 원문

UI 평가는 1/2/3을 기준으로 했습니다. 아래는 같은 조건의 별도 sanity 응답입니다.

**A / strength 0**

```text
너 진짜 늦었나? 진짜 늦었다니까. 근데 너무 늦은 게 아니라서 그냥 장난치면서 뭐라고 해.
```

**B / strength 0**

```text
친구네, 오늘 학교 끝나면 우리 둘이서 성남동으로 놀러 갈까?
```

**C / strength 0**

```text
야 내일 아침에 학교 가는 거 알잖아? 야 오늘 밤 늦게까지 게임을 하라고? 야 내일 학교는 안 가.
```

B0는 B2와 완전히 같습니다. A0에도 `늦었나?`가 남습니다. C0는 학교를 추가하고 “내일 학교는 안 가”라고 하여 일찍 일어나야 한다는 요청 취지와 어긋납니다. 0을 포함한 말투 분리도 이 샘플에서는 안정적이지 않습니다.

## 판정과 남은 이슈

| 확인 항목 | 이번 관찰 |
| --- | --- |
| 1: 표준어 중심 + 가벼운 지역 표현 | 표준 구어체 중심이나 자연스러움·의미 문제 있음; 분명한 지역성 근거 약함 |
| 2: 자연스러운 일상 울산 말투 | 세 프롬프트 모두 충분히 확인되지 않음 |
| 3: 더 적극적인 방언 어휘/어미 | A2=A3, B1=B3; C도 2보다 강한지 불명확 |
| 1 < 2 < 3 | 세 프롬프트 모두 확인되지 않음 |
| 아이가/데이/뭐하노/퍼뜩 남발 | UI 강도 출력 9개에서 모두 나타나지 않음. 남발은 없지만 자연스러운 방언이라는 증거도 아님 |
| 기타 반복·과장 | 진짜/야 반복, 어색한 호칭·비표준 형태·모호한 끝맺음 있음 |
| 의미 보존 | 각 프롬프트에서 일부 상황은 유지하나 누락·추가·거절 불명확이 있음 |
| 문장 수 | B의 모든 강도가 3–5문장 조건 미충족 |

현재 prompt-based dialect_strength가 이 세 입력에서 유의미하고 순서 있는 강도 제어를 제공한다고 주장할 근거는 부족합니다. 단일 greedy 조건·3개 상황의 관찰 범위를 유지하며, 더 넓은 프롬프트·sampling 조건·네이티브 화자 평가는 미실시입니다. 이번 작업에서는 모델·코드·prompt 정책 수정이나 추가 학습을 하지 않았습니다.
